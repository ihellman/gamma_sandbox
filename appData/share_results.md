## Step 3: Share your results

Once an analysis has run, **Download HTML Report** produces a single, self-contained HTML file that opens in any browser with no software installed and can be attached to an email, stored with collection records, or shared with partner institutions.

The report records everything needed to reproduce and discuss the result:

* the taxon, tool version and date, so results from different runs can be compared later;
* an occurrence summary by data source, with the number of records, records with coordinates, and germplasm and reference counts;
* the three scores, the FCS and the priority category, as a table and a chart;
* an interactive map of the range, the germplasm buffers, the GRS gap and the ERS regions, with the protected-area layer available;
* a table of the ecoregions in the range showing which ones hold germplasm records and how many;
* a searchable table of every record used, with links back to the original GBIF occurrence pages;
* definitions of the scores and the record categories.

The working dataset itself can be exported from the Data Analysis page with **Export Analysis Data**, so a cleaned set of records can be re-used, shared for review, or uploaded again for a later comparison.
